Estructura y sintaxis de CSS

¿Qué es?

CSS (Cascading Style Sheets u hojas de estilo en cascada) es un lenguaje que se utiliza para dar diseño y apariencia a las páginas web. Permite modificar colores, tamaños, espacios, fuentes y la distribución de los elementos HTML.

¿Para qué sirve?

Sirve para separar el contenido de una página web de su presentación visual. HTML organiza la información y CSS define cómo se verá, haciendo que el sitio sea más atractivo, ordenado y fácil de utilizar.

¿Cómo funciona?

CSS funciona mediante reglas que indican qué elementos HTML se van a modificar y qué estilos se les aplicarán. El navegador lee esas reglas y muestra la página con el diseño establecido.

¿Cuál es su estructura?

Una regla CSS está formada por un selector y un bloque de declaraciones. El selector identifica el elemento HTML; dentro de las llaves se escriben las propiedades y sus valores.

h1 {
    color: blue;
    font-size: 32px;
}

Partes de una regla CSS

  • Selector: indica a qué elemento HTML se aplicará el estilo. En el ejemplo, es h1.
  • Propiedad: define qué característica se desea cambiar, como color o font-size.
  • Valor: establece el resultado de la propiedad, como blue o 32px.
  • Declaración: es la combinación de una propiedad y un valor, terminada en punto y coma.
  • Bloque de declaraciones: es el conjunto de declaraciones que se encuentra entre llaves.

Importancia de la sintaxis

Es importante escribir correctamente la sintaxis para que el navegador pueda interpretar los estilos. Cada regla debe tener sus llaves, dos puntos entre la propiedad y el valor, y punto y coma al finalizar cada declaración.
